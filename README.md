# Responsible and Safe AI 🤖

This repository contains **Previous Year Question Papers (PYQs), assignments, and solutions** for the Responsible and Safe AI subject. It is created to help students prepare for examinations, complete assignments, and understand important concepts.
## If files not get open here then download raw file and open it on the browser.

## 🎯 Purpose

- Keep all subject-related study materials organized in one place.
- Help students prepare for internal and semester examinations.
- Provide reference solutions for assignments and practice questions.
- Encourage understanding of responsible, ethical, and safe AI principles.

*Note: The folder structure may vary depending on the materials uploaded.*

## 🤝 Contributions

If you have additional question papers, assignment solutions, notes, or useful study resources, feel free to contribute by opening a pull request.

## ⚠️ Disclaimer

This repository is intended for educational purposes only. The solutions are shared as study references. Students should understand the concepts and follow their institution's academic integrity guidelines.
